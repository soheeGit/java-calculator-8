# java-calculator-precourse

## 1. 입력 처리 기능
- [x] 사용자로부터 문자열 입력받기
- [x] "덧셈할 문자열을 입력해 주세요." 안내 메시지 출력
- [x] 빈 문자열 입력 시 0 반환 처리

## 2. 기본 구분자로 문자열 분리 기능
- [x] 쉼표(`,`)를 구분자로 문자열 분리
- [x] 콜론(`:`)을 구분자로 문자열 분리
- [x] 여러 구분자가 혼합된 경우 처리 (정규식 사용)

## 3. 커스텀 구분자 파싱 기능
- [x] 커스텀 구분자 존재 여부 확인 (`//`로 시작하는지 검사)
- [x] `//`와 `\n` 사이의 문자를 커스텀 구분자로 추출
- [x] 커스텀 구분자가 있을 경우 `\n` 이후 부분을 실제 계산할 문자열로 추출
- [x] 커스텀 구분자로 문자열 분리

## 4. 숫자 변환 및 검증 기능
- [x] 분리된 문자열을 정수로 변환
- [x] 숫자가 아닌 값 입력 시 `IllegalArgumentException` 발생
- [x] 음수 입력 시 `IllegalArgumentException` 발생
- [x] 양수만 허용하는 검증 로직 구현

## 5. 덧셈 계산 기능
- [x] 변환된 숫자들의 합계 계산
- [x] 빈 문자열일 경우 0 반환
- [x] 계산 결과 반환

## 6. 결과 출력 기능
- [x] "결과 : {결과값}" 형식으로 결과 출력

## 7. 예외 처리 및 애플리케이션 흐름
- [x] `IllegalArgumentException` 발생 시 처리
- [x] 예외 발생 시 애플리케이션 종료
- [x] `Application` 클래스의 `main` 메서드에서 전체 흐름 연결

## 8. 정규식 특수문자 처리
- [x] 커스텀 구분자가 정규식 특수문자인지 확인
- [x] 정규식 특수문자를 일반 문자로 이스케이프 처리
- [x] `Pattern.quote()` 메서드를 사용하여 안전하게 처리
- [x] 특수문자를 포함한 커스텀 구분자로 문자열 분리 테스트
